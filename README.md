# Kebab Kafe — Restaurant Website

A modern, customer-facing website for Kebab Kafe, built to showcase the menu
and give visitors a clean, easy browsing experience. Built as a real
restaurant website, not a practice project.

## Features

- Menu showcase with categories and pricing
- Responsive design for mobile and desktop
- Fast load times powered by Vite

## Tech Stack

- React.js
- Vite
- JavaScript
- HTML5 / CSS3
- ESLint

## Getting Started

Clone the repo and install dependencies:

\`\`\`bash
git clone https://github.com/furqan-svg/Kebab-Terminal.git
cd Kebab-Terminal
npm install
\`\`\`

Run the development server:

\`\`\`bash
npm run dev
\`\`\`
